# Владимир Видео ТВ для Fire Stick

## Сборка APK

1. Распакуй ZIP и замени файлы по тем же путям в репозитории Vladimir-Video-TV. В корне должны находиться `app`, файлы Gradle, папка `relay` и `.github/workflows/build-apk.yml`.
2. В Secrets and variables → Actions создай секрет `ANDROID_DEBUG_KEYSTORE_B64`. Если секрет уже настроен, используй его как есть. Для обновления поверх установленной версии нужен тот же ключ, которым подписан предыдущий APK. Храни ключ отдельно от исходников и используй тот же ключ для последующих обновлений этого приложения.
3. В Actions запусти сборку. После успешного завершения скачай архив из Artifacts и распакуй APK.

## Подключение с телефона из другого дома

Запусти `node relay/server.mjs` на сервере за HTTPS-прокси. Для работы сервиса нужны Node.js и публичный HTTPS-адрес. Задай `PUBLIC_ORIGIN` равным этому адресу. По умолчанию процесс слушает `127.0.0.1:8080`, а HTTPS-прокси должен передавать туда запросы. Для сессии используется один процесс. Перезапуск завершает выданные сессии.

На ТВ открой «Подключить с телефона», укажи HTTPS-адрес сервера и передай фото QR-кода человеку, которому доверяешь. В браузере телефона появится форма отправки плейлиста. На ТВ нужно подтвердить добавление. Код действует 10 минут и рассчитан на одну отправку. Адрес плейлиста нужен для воспроизведения и обрабатывается сервером. Используй собственный доверенный сервер.
